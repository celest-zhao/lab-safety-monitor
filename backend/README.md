# 实验室环境监测系统

**平台**：STM32L431VCTx（Cortex-M4，256 KB Flash / 64 KB RAM）+ Huawei LiteOS
**功能**：温湿光气四路加权融合评分 → L1~L4 四级告警 → 本地声光/排风/补光 + 边缘 AI 双通道预判 + TFT 多页显示 + 华为云上报（离线补传）

---

## 一句话设计立场

> **分数看趋势，等级管告警。** 任何单一物理量都不能把系统推到 L4——L4 只能由规则的"气体 + 时长 + 是否有人"产生。这样"为什么长鸣"永远有一个可回答的原因。

---

## 系统边界

| 能力 | 实现 |
|---|---|
| 采集 | SHT30（温/湿）、BH1750（lux）、MQ-5（可燃气开关量）、AS312（人体开关量），1 s 周期 |
| 融合评分 | 4 因子加权求和 0~100，映射 L1~L4；温湿度取 `max(温度分, 湿度分)`，不互相稀释 |
| 规则层 | 火情、气体紧急（≥8 s）、有人漏气（≥3 s）三条强制抬升 L4 |
| AI | FISVDD 离群检测（判"现在"）+ 30 点线性回归升温预判（判"要去哪"） |
| 执行器 | 四路 LED + 蜂鸣器分级、排风扇 PA8、补光灯 PB15、LD3320 语音（仅气体 L4） |
| 上云 | 华为云智慧家居 0x02，MQTT 属性上报，W25Q128 离线环形日志 + 断网补传 |

**明确不做的**：没有休眠（低功耗只是降采样）、没有气体浓度值（MQ-5 只有开关量）、没有执行器闭环检测。

## 软件结构

三个 LiteOS 任务：`control_task`（prio 0，协议+网络）、`view_task`（prio 1，场景维护）、`sensor_task`（prio 2，采样+融合+执行器+显示）。

单周期数据流：`Sensor_Sample → Alarm_Evaluate → Actuator_Update → Fusion_Evaluate → AiMonitor_Process → Fusion_ApplyAi → Fusion_Stabilize → 显示/上报`。

关键代码位置：`Hardware/HANDLE/handle_config.h`（阈值）、`task_user/ai_monitor.h`（AI 参数）、`Hardware/FUSION/fusion.c`（融合评分与规则）。

## 阈值速查

### 等级体系

| 综合分 | 等级 | LED | 蜂鸣器 |
|---|---|---|---|
| [0, 25) | L1 NORMAL | 灭 | 不响 |
| [25, 50) | L2 HINT | 慢闪 500 ms | 不响 |
| [50, 75) | L3 WARN | 快闪 200 ms | 间歇短鸣 |
| [75, 100] | L4 EMERGENCY | 急闪 50 ms | 持续长鸣 |

### 权重与单项天花板

| 因子 | 权重 | 满分贡献 | 单独可达 |
|---|---|---|---|
| 温湿度 | 0.30 | 30 | L2 |
| 气体 | 0.55 | 55 | L3（实际规则拉 L4） |
| 人体 | 0.00 | 0 | — |
| 光照 | 0.15 | 15 | 不可达 |
| AI 加分 | — | +6.5 | 仅抬 L1→L2 |

三条结论：(1) 无气体时理论最高 45 分，进不了 L3；(2) 所有 L4 由规则产生；(3) AI 不能独立报警。

### 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 温度正常区间 | 0~40 ℃ | 软肩从 36 ℃ 起给分 |
| 湿度正常区间 | 20~80 %RH | |
| 光照下限 | 100 lux | 低于补光 |
| 气体 HINT/WARN/L4 | <3s / 3~8s / ≥8s | 按时长分级 |
| 等级升级/降级防抖 | 3s / 5s | L4 立即生效 |
| L2 迟滞 | 3.0 分 | 退出需 <22 分 |

### 规则

| 规则 | 条件 | 动作 |
|---|---|---|
| 1 火情 | 气体 ≥3s + 温度越界 | → L4 |
| 2a 气体紧急 | 气体 ≥8s，不看人体 | → L4 |
| 2b 有人漏气 | 有人 + 气体 ≥3s | → L4（提前 5s） |
| 4 持续超时 | — | 已关闭 |

### AI 评分参数

| 参数 | 值 | 说明 |
|---|---|---|
| AI_SCORE_EN | 1 | 参与评分 |
| AI_SCORE_DEADBAND | 25 | 偏离度 <25 不触发 |
| AI_SCORE_GAIN | 0.10 | 每 1 点偏离加 0.1 分 |
| 满分上限 | 6.5 分 | 不能独立报警 |

## 执行器联动

| 触发 | 判据 | 动作 |
|---|---|---|
| 风扇 | 温湿度非 NORMAL 或 气体 ≥WARN | PA8 吸合，恢复后延时 60s |
| 补光 | 光照非 NORMAL | PB15 点亮 |
| 蜂鸣器 | 融合 L3/L4，静音时关 | PE8 |
| 语音 | 气体 L4 上升沿 + 未静音 | 单次播报 |
| LED | 各自模块等级 | 分级闪烁 |

## 低功耗模式

KEY4 长按 3s 进入。采样降到 30s，融合和 AI 不执行，执行器和指示关闭。气体检出或温湿度越界自动退出。最坏 40s 发现越界（30s 间隔 + 8s 传感器响应）。
